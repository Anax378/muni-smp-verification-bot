
admin commands:
/regs_by_dc_name
	list all registrations initiated from a discord profile with that name (at the time)

/regs_by_email
	list all registrations using this email

/get_email_bans
	list all banned emails

/is_email_banned
	check if email is banned

/ban_email
	ban email
	does not remove registrations from database
	does not remove discord role
	removes mc role
	moves player to lobby

/unban_email
	unban email
	
/get_email_acc_limit
	get how many mc usernames an email can be used to verify (deafult is 1)

/set_email_acc_limit
	set the max number of mc usernames that this email can be used to verify
